# 供应商话单核验场景

通信结算员每天接收分片CDR与供应商会话账单。网络重发会产生重复片段，换网记录可能重叠，同一会话也可能存在断续通话。直接相加片段或按最早到最晚跨度收费都会多算。

标准样例包含14个会话42个片段，每会话片段为00:00–00:40、00:30–01:10、02:00–02:20。有效90秒，原始100秒，重叠10秒，间隙50秒。国内收费0.40元，漫游3.00元，样例总额16.00元。

脏样例加入冲突分片、缺序会话、旧编码、全角序号、无偏移时间、反向时长与未知区域。结算员依次接收、校验、拼接与计费，在坏单隔离复核无法确定的会话，对照供应商差额后归档当前版本。所有费用由后端规则计算，终端日志只显示本次真实执行的数据。

## 跨零点补片

账单发出后运营商常补送跨零点分片。补片台账按UTC+8日历日划分账期，账期 open 时补片触发重开原账（新版本保留旧版本），已出账 issued 后补片不再改写原账，而是把逐会话差额结转到下一账期。重开若会让原账已计费会话被整会话隔离则视为不安全，自动回退结转。同一补片原文或同一分片指纹重复到达都不二次累计，原子切换失败时回滚到上一版，原始补片始终归档可下载。页面与三份CSV导出（账期水位、差额来源、补片台账）同源，可逐期核对分片水位、原账、重算结果与差额来源。
